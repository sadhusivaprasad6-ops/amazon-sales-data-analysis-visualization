# 🛒 Amazon Sales Data Analysis & Visualization

## 📌 Project Overview

This project focuses on analyzing Amazon sales data using Python. It demonstrates data cleaning, exploratory data analysis (EDA), and visualization techniques to uncover valuable business insights. The project helps understand sales performance, product popularity, customer purchasing patterns, and regional trends.

---

## 🎯 Objectives

- Load Amazon sales data from an Excel file
- Clean and preprocess the dataset
- Handle missing values and duplicate records
- Perform exploratory data analysis (EDA)
- Analyze sales and profit performance
- Identify top-selling products
- Compare sales across categories and regions
- Visualize business insights using charts
